# Новогодний эфир «Вместе радио»

Статический лендинг Megapolis Media с десктопной и мобильной компоновками из макета Figma.

## Запуск

```sh
docker compose up --build -d
```

Сайт откроется по адресу [http://127.0.0.1:18174](http://127.0.0.1:18174). Переменная `VMESTERADIO_PORT` задаёт порт на хосте.

## Выкладка

После обновления `master` GitHub Actions запускает выкладку на [vmesteradio.knzteam.ru](https://vmesteradio.knzteam.ru/). Для запуска требуется подтверждение владельца в environment `production`. Сервер публикует только файлы из `public/` для актуального коммита `master`.

## Ветки

- `dev` — единая рабочая ветка команды и ветка по умолчанию. Участники с прямым доступом работают в ней: pull → изменения → проверки → commit → повторная синхронизация → push в ту же `dev`.
- `master` — версия для production. Владелец обновляет её через PR из `dev`. При подключении выкладки подтверждение владельца настраивается в environment `production`.
- `<github-login>` — постоянная ветка внешнего участника без прямого доступа в `dev`. Он работает в fork и присылает PR. Уже существующие личные ветки команды автоматически не удаляются; новые задачи команда выполняет в `dev`.

В `master` запрещён прямой push. В обеих ветках запрещены удаление и force push, включая аккаунты с правом прямой записи в `dev`. Работайте под своим аккаунтом.

## Начало работы

Читайте [CONTRIBUTING.md](CONTRIBUTING.md). AI-ассистент обязан прочитать [AGENTS.md](AGENTS.md).

Публичный репозиторий доступен для чтения всем. Для прямого push в `dev` участнику нужны принятый доступ Write и персональное исключение из обязательного PR в действующем ruleset. Остальные участники работают через fork и PR. Перед каждой задачей и каждым push получите свежую `dev` и сохраните изменения других разработчиков.

Эти правила описывают проекты, созданные из шаблона. Для изменений самого шаблона ориентируйтесь на его действующие права и правила защиты веток.

Для владельца: [создание проектов и администрирование](docs/MAINTAINERS.md).

В Git отправляем исходники и готовые ассеты сайта. Секреты, тестовые картинки, брейншторминг, промежуточные генерации и AI-артефакты остаются локально в игнорируемых каталогах. Подробный порядок — в CONTRIBUTING.md и AGENTS.md.
